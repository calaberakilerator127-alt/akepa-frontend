\section*{TEMA}
Uso de grillas para adaptar pantallas en diseño web responsive mediante CSS Grid.

\section*{OBJETIVOS}
\begin{itemize}
  \item Describir las columnas, filas, separaciones y unidades relativas de una grilla CSS.
  \item Aplicar una grilla flexible y media queries para cambiar la distribución de una interfaz según el ancho disponible.
  \item Verificar, mediante capturas, la reorganización de una misma interfaz en escritorio, tableta y móvil.
\end{itemize}

\section*{MARCO TEÓRICO}
CSS Grid organiza los hijos directos de un contenedor en una cuadrícula bidimensional de líneas horizontales y verticales. Al declarar \texttt{display: grid}, el elemento padre se convierte en contenedor de grilla; sus hijos pasan a ser elementos de la grilla. Las líneas delimitan columnas y filas, y la intersección de una columna con una fila forma una celda \cite{mdn-grid-concepts}.

Las propiedades \texttt{grid-template-columns} y \texttt{grid-template-rows} definen las pistas. La abreviación \texttt{repeat(3, 1fr)} crea tres columnas. La unidad \texttt{fr} reparte el espacio libre entre las pistas; por ello \texttt{2fr 1fr} asigna a la primera el doble de espacio libre que a la segunda \cite{mdn-grid-concepts}.

\subsection*{Grilla flexible}
El siguiente bloque usa \texttt{auto-fit} para calcular cuántas columnas de al menos 180 px caben en el contenedor. Cuando el ancho disminuye y ya no cabe otra columna, una tarjeta pasa a la fila siguiente. El \texttt{gap} conserva el espacio entre tarjetas.

\begin{lstlisting}
.tarjetas {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 1rem;
}

.tarjeta { padding: 1rem; border: 1px solid #c7d9eb; }
\end{lstlisting}

\texttt{minmax(180px, 1fr)} evita que una columna sea menor de 180 px y permite que use una fracción del espacio libre. Este patrón permite que el número de columnas cambie sin una media query específica \cite{mdn-grid-layout}.

\subsection*{Puntos de quiebre y media queries}
Un breakpoint es el ancho en el que se aplica una regla de diseño distinta. Una media query contiene una condición; las declaraciones internas se aplican si el viewport cumple esa condición \cite{mdn-responsive,mdn-media}.

\begin{lstlisting}
/* Base: movil */
.app {
  display: grid;
  gap: 1rem;
  grid-template-areas: "header" "nav" "main" "aside" "footer";
  grid-template-columns: 1fr;
}

/* Tableta: dos columnas */
@media (min-width: 48rem) {
  .app {
    grid-template-areas: "header header" "nav main" "aside main" "footer footer";
    grid-template-columns: minmax(10rem, .8fr) minmax(0, 2.2fr);
  }
}

/* Escritorio: tres columnas */
@media (min-width: 70rem) {
  .app {
    grid-template-areas: "header header header" "nav main aside" "footer footer footer";
    grid-template-columns: minmax(11rem, .8fr) minmax(0, 2.4fr) minmax(13rem, .9fr);
  }
}
\end{lstlisting}

En la regla base, las cinco áreas quedan en una columna. En el primer bloque \texttt{@media}, la condición \texttt{min-width: 48rem} activa dos columnas. En el segundo bloque, la condición \texttt{min-width: 70rem} activa tres columnas y coloca \texttt{aside} a la derecha de \texttt{main}.

El documento HTML debe incluir \texttt{<meta name="viewport" content="width=device-width, initial-scale=1">}; este elemento permite que los navegadores móviles usen el ancho del dispositivo al evaluar las media queries \cite{mdn-responsive}.

\section*{CONCLUSIONES}
\begin{itemize}
  \item Las columnas, filas y \texttt{gap} del contenedor permiten separar los elementos visibles sin márgenes individuales entre cada celda.
  \item Las pistas con \texttt{fr}, \texttt{minmax()} y \texttt{auto-fit} cambian su ancho o número de columnas conforme varía el espacio disponible.
  \item Las áreas declaradas en cada media query permiten que \texttt{nav}, \texttt{main} y \texttt{aside} cambien de posición en el mismo HTML.
\end{itemize}

\section*{RECOMENDACIONES}
\begin{itemize}
  \item Crear primero una estructura legible de una columna y añadir columnas donde el contenido ya disponga de espacio.
  \item Probar anchos intermedios, no solo los tres anchos de las capturas, para detectar texto comprimido, botones pequeños u overflow.
  \item Usar \texttt{minmax(0, 1fr)} para una columna que puede contener elementos largos y evitar desbordamiento horizontal.
\end{itemize}
